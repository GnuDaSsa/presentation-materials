# 1. Scene
첨부한 캐릭터 시트는 주인공 사진우의 얼굴과 의상 참조다. 검은 가르마 머리, 자연스럽게 둥근 턱, 작은 미소, 검은 재킷과 회색 티셔츠, 검은 바지와 운동화를 동일하게 유지한다. 단일 프레임의 컬러 애니메이션 영화 장면. 나주역 앞 광장에 막 도착한 사진우가 닫힌 노트북을 왼팔에 끼고 한 발 크게 내딛으며 강의장 쪽을 바라본다. 화면 전경의 오른발과 재킷 끝자락이 크게 보이고 얼굴은 화면 중상단에 배치된다. 뒤편 역사의 긴 수평선과 보도블록 대각선이 인물 쪽으로 수렴한다. 가을 아침 하늘과 넓은 유리벽의 빛을 배경으로, 인물의 기대감과 경쾌한 발걸음이 주제가 된다. 프레임 전체가 하나의 연속된 공간이다.
# 2. Camera
바닥 가까운 낮은 카메라, 광각 원근감, 전신 3/4 측면, 인물 높이는 화면의 80%, 앞발은 오른쪽 아래 전경, 역사는 작게 후경.
# 3. Lighting
왼쪽 뒤에서 들어오는 4800K 아침 햇빛, 재킷 가장자리의 가는 따뜻한 림, 얼굴은 부드러운 반사광, key:fill 2:1.
# 4. Color grading
검정 #252731, 크림 #F2E7CF, 청록 #347C89, 주황 #E79C51, 하늘 #A8C8D2. 밝은 중간톤과 절제된 채도.
# 5. Texture/Medium
단정한 2D 셀 애니메이션, 두 단계 음영, 얼굴은 참조의 닮음을 유지한 손그림, 큰 형태와 굵기 변화가 있는 선, 배경은 단순한 색면.
# 6. Text-in-image
역사 상단의 실제 간판 위치에 작은 짙은 고딕체 "나주역". All text appears once, perfectly legible — no duplicate text, no extra words, no invented glyphs, no watermark.
