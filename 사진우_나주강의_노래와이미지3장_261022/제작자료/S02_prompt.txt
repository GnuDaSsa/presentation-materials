# 1. Scene
첨부한 캐릭터 시트는 사진우의 얼굴과 의상 참조다. 검은 가르마 머리, 자연스럽게 둥근 턱, 검은 재킷, 회색 티셔츠, 검은 바지의 동일한 한국인 남성이 나주의 강의실 무대에서 발표한다. 단일 프레임 컬러 애니메이션 영화 장면. 사진우는 화면 오른쪽 중경에서 왼손에 마이크를 잡고 오른손을 화면 방향으로 활짝 펴며 밝게 설명한다. 왼쪽 앞에는 청중 두 명의 어깨와 뒷머리가 크고 어둡게 잘려 들어오고, 그 사이로 강사와 가로형 스크린이 보인다. 스크린에는 강사가 만든 새와 도시의 애니메이션 그림이 큼직하게 투사된다. 청중의 어깨, 사진우, 스크린의 세 깊이로 실제 강의장 공간을 느낄 수 있다. 사진우의 얼굴이 작아지지 않도록 강사 상반신이 화면 높이의 절반을 차지한다.
# 2. Camera
앞줄 청중의 어깨 너머 시점, 중간 거리 토르소 뷰, 강사는 우측 1/3, 스크린은 왼쪽 위, 사선 원근과 자연스러운 비대칭.
# 3. Lighting
스크린의 6500K 청록 반사광과 오른쪽 천장의 4200K 따뜻한 얼굴 조명, key:fill 2:1, 부드러운 그림자.
# 4. Color grading
딥네이비 #182A3D, 크림 #F1E4C7, 청록 #398C99, 주황 #E6A358, 먹색 #252731. 얼굴과 손에 가장 밝은 명도.
# 5. Texture/Medium
손그림 2D 셀 애니메이션, 두 단계 음영, 굵기 변화가 있는 선, 피부는 평평한 따뜻한 색면, 배경의 좌석은 큰 실루엣으로 정돈.
# 6. Text-in-image
스크린 위 여백에 짧고 큰 고딕체 "같이 만들어 봐". All text appears once, perfectly legible — no duplicate text, no extra words, no invented glyphs, no watermark.
