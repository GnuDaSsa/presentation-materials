# 1. Scene
첨부한 캐릭터 시트의 사진우와 얼굴·머리·검은 재킷·회색 티셔츠를 일치시킨다. 단일 프레임 컬러 애니메이션 영화 장면. 나주의 강의실에서 사진우가 강연대의 노트북으로 이미지 생성 시연을 한다. 노트북 화면과 키보드가 왼쪽 아래 전경의 약 45%를 크게 차지하고 화면에는 커다란 푸른 새가 날아오르는 선명한 그림 한 장이 보인다. 사진우는 오른쪽 위 중경에서 노트북을 바라보며 살짝 웃고, 오른손 검지는 트랙패드에 자연스럽게 닿는다. 뒤편 스크린에도 같은 푸른 새 그림이 크게 보여 노트북 시연이 프로젝터로 연결됨을 읽을 수 있다. 전경 손, 화면 그림, 사진우의 표정 세 지점이 대각선으로 연결된다. 뒤쪽 객석은 단순한 어두운 형태로 보인다.
# 2. Camera
노트북 왼쪽에서 강사의 얼굴을 함께 담는 근접 광각 3/4 시점, 열린 화면의 앞면과 얼굴이 동시에 보이는 물리적 각도, 전경 과장과 후경 압축의 깊이.
# 3. Lighting
노트북의 6500K 푸른 빛이 손과 얼굴 아래에 약하게 반사되고, 4300K 천장광이 얼굴을 부드럽게 밝힘, key:fill 2:1.
# 4. Color grading
먹색 #252731, 청록 #348A99, 크림 #F1E4C7, 푸른새 #54BEE0, 황금 #E6A358. 화면의 푸른 새를 색의 초점으로 유지.
# 5. Texture/Medium
두 단계 음영의 2D 셀 애니메이션, 손으로 그린 윤곽, 재킷 주름은 큰 형태, 인물의 닮음과 화면의 명확한 기하관계 중심.
# 6. Text-in-image
텍스트 없는 장면. 화면은 커다란 새 그림과 작은 추상적인 인터페이스 도형만으로 구성.
