# Design System — Green Corporate Deck

레퍼런스 이미지(그린 계열 비즈니스 프레젠테이션 템플릿)에서 추출한 디자인 시스템. 1920×1080 슬라이드 기준.

## 1. 컬러

| 역할 | 값 | 용도 |
|---|---|---|
| Primary Green | `#2E9E3E` | 로고, 제목, 핵심 강조 |
| Deep Green | `#1B6B2B` | 그라데이션 어두운 끝, 본문 강조 |
| Light Green | `#8DC63F` | 그라데이션 밝은 끝, 라임 액센트 |
| Mint Tint | `#E8F5E4` | 연한 배경 블록, 카드 |
| Ink | `#1C1C1C` | 본문 텍스트 |
| Slate | `#5A5F5C` | 보조 텍스트, 캡션 |
| Paper | `#FFFFFF` | 기본 배경 |
| Night | `#0C1A0F` | 클로징/Thanks 슬라이드 배경 |

**그라데이션 (시스템의 핵심 시그니처)**
- 대각선 그린: `linear-gradient(135deg, #8DC63F 0%, #2E9E3E 45%, #1B6B2B 100%)`
- 위 그라데이션은 항상 곡면 도형(원, 물결, 사선 컷) 안에서만 사용. 슬라이드 전면 배경에 평평하게 깔지 않는다.

규칙: 한 슬라이드에 배경색은 최대 2개. 초록 위 텍스트는 항상 흰색, 흰 배경 위 제목은 Primary Green.

## 2. 타이포그래피

- 제목: **Poppins SemiBold** (대체: Montserrat)
- 본문: **Open Sans Regular** (대체: Source Sans 3)

| 토큰 | 크기 | 비고 |
|---|---|---|
| `--type-hero` | 96px | 표지 / Break Slide 타이틀 |
| `--type-title` | 64px | 일반 슬라이드 제목, 두 줄까지 |
| `--type-subtitle` | 44px | 인용문, 부제 |
| `--type-body` | 32px | 본문 |
| `--type-small` | 26px | 캡션, 출처, 페이지 번호 |

- 제목 line-height 1.15, 본문 1.55.
- 제목은 문장형이 아니라 짧은 명사구(예: About us, Market Overview).
- 강조는 볼드 + Deep Green으로만. 밑줄·이탤릭 금지.

## 3. 레이아웃

- 캔버스 1920×1080. 여백: 좌우 120px, 상단 100px, 하단 90px.
- 12컬럼 그리드, 거터 40px. 2단 본문은 6+6, 이미지+텍스트는 5+7.
- 제목과 본문 사이 간격 52px, 문단 사이 28px.
- 페이지 번호는 우측 하단, Small 사이즈, Slate 컬러.
- 로고는 좌측 하단 고정. 모든 슬라이드 동일 위치·동일 크기.

## 4. 시그니처 그래픽

이 시스템의 정체성은 **곡선**이다. 직각 카드나 좌측 보더 액센트 박스는 쓰지 않는다.

1. **원형 프레임** — 이미지를 완전한 원으로 마스킹하고, 바깥에 2~3개의 얇은 그린 링(두께 6~10px, 일부만 그려진 호)을 겹친다.
2. **사선 컷** — 슬라이드를 대각선(약 20°)으로 나누어 한쪽만 그린 그라데이션.
3. **물결 스와시** — 슬라이드 하단 또는 우측에서 들어오는 부드러운 S자 곡면. 텍스트 영역을 침범하지 않는다.
4. **코너 블록** — 우측 하단의 작은 라임색 사각/부채꼴, 페이지 번호 배경.

곡선 도형은 슬라이드당 최대 2개. 겹칠 때는 투명도 대신 명도 차이로 층을 만든다.

## 5. 슬라이드 타입

| 타입 | 구성 |
|---|---|
| **표지** | 좌측 그린 패널 + 로고·타이틀, 우측 원형 마스킹 사진 |
| **Break / 섹션** | 그린 그라데이션 전면(사진 오버레이 가능), Hero 타이틀 중앙 좌측 정렬 |
| **텍스트 본문** | 그린 제목 + 2단 본문, 하단 물결 |
| **이미지+텍스트** | 좌 이미지(원형 또는 라운드 사각) / 우 텍스트 5:7 |
| **인용** | 그린 배경, 흰 인용문 Subtitle 사이즈, 아래 화자명 Small |
| **About / 리스트** | Mint Tint 블록 위 2단 텍스트 |
| **클로징** | Night 배경, 흰 "Thanks!", 그린 아웃라인 그래픽, 연락처 3줄 |

## 6. 아이콘

- 단색 실루엣(솔리드) 스타일. 라인 아이콘과 혼용 금지.
- 흰 배경 위 Primary Green, 그린 배경 위 흰색.
- 크기 48px 기준, 원형 배지 안에 넣을 경우 배지 지름 96px.

## 7. 이미지

- 인물·오피스 사진은 원형 또는 부드러운 곡선 마스크로 잘라 쓴다.
- 사진 위 텍스트가 필요하면 그린 그라데이션 오버레이(불투명도 70~85%)를 깔고 흰 텍스트.
- 스크린샷·차트는 마스킹하지 않고 흰 배경 위에 원본 비율로.

## 8. 금지 사항

- 초록 외의 액센트 컬러 추가
- 그라데이션을 배경 전면에 평평하게 사용
- 이모지, 직접 그린 일러스트
- 24px 미만 텍스트
- 슬라이드당 본문 60단어 초과
