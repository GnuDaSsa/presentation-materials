발표 설정

‘발표 시작’을 누르고 한국어로 인사하세요. “지금부터 영어로 진행하도록 하겠습니다”를 말하면 첫 표지가 영어로 전환됩니다.

내용·디자인·대본 수정은 자동 반영합니다. 발표 중인 변경은 종료 후 반영합니다.

발표 시작 후, 현재 장의 마지막 대사와 다음 장의 첫 문장이 인식되면 한 장 넘깁니다. 꺼도 자막은 계속 따라옵니다. 원고 따라가기 모드에서 동작합니다.

자막 세부 설정

발표 원고를 자동으로 불러옵니다.

현재 장표에서 말하는 구간을 찾아 준비된 자막을 표시합니다. 원고 밖 발언은 번역하지 않습니다.

말한 내용과 다르면 위에서 마이크를 바꿔 주세요. 기본 설정은 한국어·영어 자동 인식입니다.

음성과 인식된 문장이 OpenAI로 전송됩니다. 음성 인식과 자막 번역에 API 사용료가 발생합니다. 음성과 자막은 이 앱에 저장하지 않습니다.
