영어 V1.6 · 12장 · 55개 자막 구간 · 한국어 오프닝 후 영어 발표

첫 대본은 “안녕하세요. AI반도체과 사진우 주무관입니다.”입니다. “안녕하십니까”, “여러분, 안녕하십니까”로 시작해도 첫 자막이 나옵니다. 인사 뒤에서 잠깐 쉬고 소속 소개를 이어 말해도 됩니다.
한국어 오프닝의 방문 감사 자막은 “성남”만으로도 나옵니다. “성남에”, “성남 방문”, “성남에 방문”, “성남을 찾아 주셔서”처럼 조사를 바꾸거나 “오늘 이렇게”를 생략해도 됩니다. “방문”까지 기다리지 않고 한국어·베트남어 감사 자막을 표시합니다. 자기소개의 “성남시청”과는 구분하며, 영어 전환 후의 성남 언급으로 이 자막을 다시 띄우지 않습니다. 이 트리거로 영어 표지가 전환되지는 않습니다.
발표 시작 → 마이크 허용 → 한국어 인사 → “영어로 진행” → 영어 표지로 전환 → 영어 발표를 이어갑니다. “지금부터”와 “하겠습니다”를 정확히 맞출 필요가 없습니다. “영어로 진행해보도록 하겠습니다”, “영어로 진행해 보겠습니다”, “영어로 발표하겠습니다”도 인식합니다. “국제적인 자리”에서는 전환 안내 자막만 먼저 표시하고, “영어로 진행”이 들리면 표지를 전환합니다. 자막은 한국어·베트남어로 나오며 다음 대사까지 유지됩니다. “영어로” 뒤에 잠시 쉬어도 이어서 인식합니다.
첫 → 키는 영어 전환, 그다음 → 키는 다음 장입니다. Home으로 오프닝을 다시 시작합니다. 전환 중 중복 입력은 무시합니다.
S: 왼쪽 대본 / E: 한국어·영어 / F: 전체 화면 / R: 모션 재생 / A: 자동 넘김
2번에 발표자 소개 장표를 신설했습니다. 자기소개는 직접 말하는 1인칭입니다. V1.6의 정책 사실·수치·사업명을 유지하면서 영어 대본을 발음하기 쉬운 표현으로 다듬었습니다. 임의로 늘린 설명은 되돌렸고 기존 대사 앞에 한국어 오프닝을 추가했습니다. 자기소개·AI Champion Black·AI 활용 소개를 포함하고 최종 PDF의 얼라이언스를 7장으로 복원했습니다. 기존 50개 대사를 유지하고 얼라이언스 5개 구간을 추가했습니다.
첫 번째 인프라 장표의 짧은 첫 두 문장을 한 자막 구간으로 묶었습니다.
현재 장표 안에서는 대사 순서를 지키지 않아도 됩니다. 뒤쪽 대사를 먼저 말하거나 앞 대사로 돌아가도 해당 자막을 찾습니다. 말하는 도중 순서를 바꿔도 잠깐 쉴 필요가 없습니다. 모든 대사를 같은 기준으로 비교하며, 시작이 비슷한 문장은 구별되는 단어가 들리면 선택합니다. 영어는 어순 변경과 짧은 재표현도 허용합니다. 이 기능은 발표 시작과 함께 적용되며 별도 설정이 필요하지 않습니다.
영어는 관사·대명사를 제외한 핵심 단어를 비교합니다. 같은 장표에서 구별되는 짧은 핵심 단어 2개가 분명하게 들리거나, 3개 이상이 충분히 겹치면 문장을 줄여 말해도 자막을 선택합니다. help/support, teach/train, finished/completed 같은 동의어도 연결했습니다. “Help companies grow faster”, “Skilled workers”, “finished by 2030”처럼 말할 수 있습니다. 여러 대사에 공통인 단어만 들리면 더 기다립니다. 문장 전체의 의미를 판단하는 추가 AI 요청은 사용하지 않습니다. 발표 중에는 자동 갱신을 미루므로 수정 후에는 발표 종료 → 새로고침 → 발표 시작으로 적용합니다.
5장 세 사업 소개는 영어 센터명·사업명으로 자막을 선택합니다. System IC Verification Center: verification / validation / system IC. Semiconductor Testing Project for the Advanced Defense Industry: defense / defence / semiconductor testing / testing project. Advanced Equipment Sharing Program for Fabless Companies: sharing / advanced equipment / equipment sharing / fabless equipment. first/second/third, first project, number one 같은 순서 표현만으로는 사업 자막을 띄우지 않습니다. “First, infrastructure”는 인프라 도입 자막을 표시하고, 검증센터 자막으로 바뀌지 않습니다. the/a/an, is 같은 관사와 연결어를 바꾸거나 생략해도 되며, 순서를 다르게 말해도 영어 명칭이 가리키는 사업을 선택합니다. 여러 사업을 한 번에 인식하면 마지막으로 식별한 사업의 자막을 표시합니다. 이 방식은 해당 세 사업이 있는 현재 장표에만 적용합니다.
5장 첨단장비 공동이용지원사업은 “advanced equipment”, “advancer equipment”, “equipment sharing”처럼 명칭을 짧게 말해도 인식합니다. 두 단어 사이에 쉬어도 됩니다. “third”, “thrid”, “3rd”, “third equipment”, “third advanced”만으로는 선택하지 않습니다. “advanced”는 앞 사업명에도 있어서 장비 관련 단어를 더 기다립니다.
10장 첫 설명은 두 문장입니다: “The first three floors will be for support facilities.” / “The System Semiconductor Development Support Center will be here.” 대본에는 줄을 나누고, 자막은 한 구간으로 연결했습니다. 현재 장표에서는 three floors, development support center로도 표시됩니다. 예전 What makes… 도입부 인식도 유지합니다. 다른 층수·부정문·실제 질문은 제외하며, 짧은 키워드만으로 앞 장에서 자동 이동하지 않습니다.
장표는 원래 16:9 비율로 최대 크기로 표시합니다. F를 누르면 전체 화면입니다. 자막용 여백은 없으며, 자막은 장표 위에 반투명 검정 박스로 겹쳐 표시하고 다음 구간까지 유지합니다. 자막이나 왼쪽 대본을 열어도 장표 크기는 바뀌지 않습니다.
전체화면에서는 제목 위 여백과 본문 사이 간격을 줄여 내용을 위쪽에 배치합니다. 교육 모집인원, 연구센터 위치·일정, 층별 기능의 연결 문구도 위로 올라갑니다. 장표 전체를 축소하거나 자막 전용 행을 만들지 않으며, 자막이 나타나도 배치가 움직이지 않습니다. 일반 창의 배치는 기존대로 유지합니다.
장표는 준비된 화면끼리 바로 전환합니다. 글자·사진·층 도형의 상승·페이드·확대 효과는 없습니다. R은 장표를 새로 만들지 않고 선·비율 도형과 연구센터 영상만 다시 재생합니다.
현재 장 마지막 구간을 인식한 뒤, 다음 장 도입부의 핵심 단어가 충분히 겹치면 한 장씩 이동합니다. 영어는 관사 생략, 어순 변경, 짧은 재표현과 작은 인식 오류를 허용합니다. 짧은 장 소개를 생략하고 첫 본문부터 말해도 따라옵니다. 다른 장에서도 반복되는 센터명만으로는 이동하지 않고, 해당 장을 구별하는 내용까지 확인합니다. 자동 넘김 OFF, 다른 수치, 부정문과 실제 질문에는 자동 이동하지 않습니다. 자동 넘김을 꺼도 현재 장의 자막은 계속 따라옵니다.
음성 인식은 API를 이용하며 실제 환경에서 0.6초를 보장하지 않습니다.
한국어·베트남어 자막은 현재 영어 대본에 대응하는 번역 초안입니다.
