# Seongnam - English Presentation V1.6

사용자 제공 V1.6을 기반으로 발표자 소개를 추가하고, 발음하기 어려운 표현을 다듬었습니다. 7분을 채우기 위해 임의로 추가한 설명 14개는 요청에 따라 되돌렸습니다. 기존 영어 대사 47개 문단은 유지하고, 앞에 사용자가 준 한국어 오프닝 3개 구간을 추가했습니다. 추가 요청에 따라 3장에서는 팹리스 40%라는 산업 기반을 기업의 빠른 성장을 돕는 지원 의지와 연결했습니다. 소요 시간은 리허설 참고용이며 시간에 맞춰 기존 대사를 삭제하지 않습니다.

## 실행

바탕화면 성남 영어발표 바로가기 또는 배포 폴더 01_영어발표시작.cmd를 더블클릭합니다. 서버는 자동 준비되며 기본 화면은 영어입니다. 기존 주소 http://127.0.0.1:3230/?lang=en 에서 최신 버전을 봅니다. 바탕화면 폴더의 3232도 같은 소스를 사용합니다.

S: 왼쪽 영어 대본, E: 한국어/영어, F: 전체 화면, G: 전체 보기, R: 모션 재생, P: 모션 켜기/끄기, O: 원본 보기, A: 자동 넘김. 화면의 발표 시작을 누르고 마이크를 허용한 뒤 영어로 발표합니다. 자동 넘김을 꺼도 자막은 계속 따라옵니다. HTML을 파일 주소로 직접 열지 말고 실행 파일을 사용하세요.

## 한국어 오프닝

방문 감사 자막은 한국어 오프닝에서 “성남”만으로도 표시됩니다. “성남에”, “성남 방문”, “성남에 방문”, “성남을 찾아 주셔서”처럼 조사를 바꿔도 됩니다. “오늘 이렇게”를 말할 필요 없이 앞부분을 자유롭게 바꿀 수 있습니다. 자동 언어 판별에서도 한국어로 말한 단독 “성남”을 한국어 오프닝으로 처리합니다. 이 트리거는 첫 장의 한국어 감사 대사에 적용하며 자기소개의 “성남시청”, 다른 장표, 영어 전환 뒤의 단독 성남 언급과 구분합니다. “성남”이 “성남시청”의 일부일 수 있는 중간 인식에서는 단어 경계나 조사 또는 확정 인식이 도착할 때 판별합니다. 기존 한국어·베트남어 감사 자막은 유지합니다.

처음 표지는 한국어입니다. “국제적인 자리”에서 전환 안내 자막이 먼저 나오고, “영어로 진행”을 말하면 같은 표지가 약 1.2초 동안 영어로 전환됩니다. “지금부터”나 정해진 종결어미가 없어도 됩니다. “진행해보도록 하겠습니다”, “진행해 보겠습니다”, “영어로 발표하겠습니다”, “영어로 말씀드리겠습니다”도 인식합니다. 표지 전환과 한국어·베트남어 자막에 같은 짧은 트리거를 사용하며 “영어로”와 “진행” 사이에 잠시 쉬어도 됩니다. 첫 번째 → 키도 영어 전환, 전환 후 다음 → 키는 다음 장 이동입니다. 버튼과 발표자 창의 다음 장 조작도 같습니다. Home은 한국어 오프닝으로 돌아갑니다. 자동 넘김 OFF여도 이 오프닝 전환은 동작합니다. 음성 인식은 한국어·영어 자동이며 기존 한 연결을 유지합니다.

## 구성

영어 장표는 12장입니다: 표지 / 발표자 소개·AI Champion Black / 산업 기반 / 세 전략 / 개발지원센터 세 사업 / 장비·도구·기술지원 / 성남 시스템반도체 얼라이언스 / 인재양성 / 연구센터 / 층별 기능 / 정책 목표 / 마무리. 최종 PDF에 있는 얼라이언스(77개사: 공급기업 55·수요기업 22)를 7장으로 복원했습니다. 새 2번 장에는 강의 프로필 사진, 성남시청 AI혁신국 AI반도체과 반도체팀 소속, AI 챔피언 블랙 과정 수료, AI로 직접 제작한 발표자료·실시간 자막을 담았습니다. 블랙은 행정안전부 AI 챔피언 프로그램의 최고 등급으로 표기했습니다. 개인 수료 사실은 발표자 제공 내용이며, 과정 등급은 행정안전부 2026년 5월 7일 보도자료를 확인했습니다. 사업명은 V1.6의 축약 영문명을 사용합니다.

원본 PDF의 수치·교육조건·연구센터 계획을 유지했습니다. 제공된 한국어 PDF 11장은 public/source-final/presentation.pdf에 그대로 보존했습니다. 이전 작업 상태는 .build/before-v16에 있습니다. HTML 9장은 발표자가 제작한 3D 뷰어(https://gnudassa.github.io/pangyo-3d-viewer/?v=0.7)를 직접 녹화한 10.12초 무음 영상을 사용합니다. 기획안의 추정 모델로 표시하며 지도 데이터 출처도 함께 표기했습니다. 이번 공유용 영문 PDF도 12장으로 갱신했습니다. 연구센터 영상 장에는 같은 3D 모델의 정지 화면을 표시합니다.

영상은 장표 진입 시 한 번 재생한 뒤 마지막 화면을 유지합니다. 영상의 Play/Pause/Replay, P(움직임 일시정지), R(장면 다시 재생)을 사용할 수 있습니다. 다른 장이나 원본 보기로 이동하면 멈추며, 인터넷 없이도 재생됩니다. 운영체제의 모션 줄이기 설정에서는 자동 재생하지 않고 Play 버튼을 표시합니다. 영상이 로드되지 않으면 같은 모델의 정지 화면을 표시합니다.

장표를 넘기면 12장 모두 본문·도형 애니메이션이 자동 재생됩니다. 제목·배경·사진은 고정하고 본문은 제자리에서 왼쪽부터 순서대로 펼쳐집니다. 연결선, 원형 비율, 면적 막대는 약 1초에 걸쳐 채워집니다. 다음 장의 이미지와 글꼴이 준비될 때까지 현재 장을 유지하며 화면 전체의 페이드·상승·캡처 전환은 사용하지 않습니다. R은 현재 장의 모션·영상을 다시 재생하고, P는 내용을 완성 상태로 표시하면서 모션을 끄거나 켭니다. 다시 재생할 때 장표 전체를 새로 만들지 않습니다. 연구센터 영상은 첫 프레임이 준비되기 전까지 정지 화면을 유지합니다.

## 자막·자동 이동

현재 장표 안에서는 대사 순서와 관계없이 말한 문장에 맞는 자막을 찾습니다. 뒤쪽 대사부터 시작하거나 앞 대사로 돌아가도 되며, 같은 발화 도중 순서를 바꿔도 따라옵니다. 짧은 시작 구절과 영어 재표현의 인식 기준은 현재 장표의 모든 대사에 동일하게 적용합니다. 시작이 비슷한 대사는 구별되는 단어까지 기다립니다. 발표 시작 시 기본 적용되며 별도 설정은 없습니다.

영어 유사도는 핵심 단어 비교입니다. 관사·대명사 등을 제외하고 단어 형태, 일부 인식 오타, 동의어를 정규화합니다. 현재 장표의 가중 단어 일치율 기준을 0.70에서 0.55로 낮췄으며, 다른 대사와 구별되는 핵심 단어 2개만으로도 짧은 발화를 인식합니다. 이 2단어 예외는 발화 전체가 그 조합일 때만 적용하고, 다른 주어나 부정 표현을 잘라내어 맞추지 않습니다. 3개 이상 일치하는 경우 문장 축약과 추가 표현을 더 허용합니다. help/support, teach/train, finished/completed, faster/quicker 등은 인식용으로만 연결하며 대본·번역은 변경하지 않습니다. 숫자·부정문·센터 구분과 다음 장 이동의 별도 기준은 유지합니다. 추가 의미 분석 API는 사용하지 않습니다. 발표 중에는 갱신이 보류되므로 발표 종료 후 새로고침하면 적용됩니다.

55개 영어·한국어·베트남어 구간으로 연결했습니다. 인프라 장의 짧은 첫 두 문장만 하나의 자막 구간으로 묶었습니다. 한국어 오프닝과 기존 영어 대본에 인식 기준·베트남어 자막을 맞췄습니다. 원고에 따라 준비된 자막을 선택하고 다음 대사까지 유지합니다. 장표는 원래 16:9 비율로 화면에 최대 크기로 표시합니다. F 전체 화면에서는 16:9 화면을 빈 공간 없이 채웁니다. 자막용 별도 여백은 없으며, 자막은 장표 위에 불투명도 72%의 검정 박스로 겹쳐 표시합니다. 자막과 왼쪽 대본 패널을 열어도 장표 크기는 바뀌지 않습니다.

현재 장 마지막 구간을 인식한 뒤, 다음 장 도입부의 핵심 단어가 충분히 겹치면 한 장씩 이동합니다. 영어는 관사 생략, 어순 변경, 짧은 재표현과 작은 인식 오류를 허용합니다. 짧은 장 소개를 생략하고 첫 본문부터 말해도 따라옵니다. 다른 장에서도 반복되는 센터명만으로는 이동하지 않고, 해당 장을 구별하는 내용까지 확인합니다. 자동 넘김 OFF, 다른 수치, 부정문과 실제 질문에는 자동 이동하지 않습니다. 10장의 What makes…는 질문이 아닌 원고 문장으로 인식합니다. 음성 인식에는 API를 사용하며 원고 자막 표시를 위한 별도 번역 요청은 없습니다. 실제 마이크와 네트워크 지연에 따라 0.6초 이내는 보장하지 않습니다. 이번 유사도 검증에는 모의 인식 결과를 사용했으며 마이크나 유료 음성 연결은 사용하지 않았습니다.
